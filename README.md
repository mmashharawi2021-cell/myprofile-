# Mohanad Al-Mashharawi Portfolio

موقع شخصي احترافي لعرض أعمال وخدمات مهند المشهراوي كمهندس نظم معلومات جغرافية ومطور أنظمة ويب وداشبوردات.

## الهدف

هذا الموقع مصمم ليكون واجهة ثقة مهنية، وليس مجرد صفحة تعريفية. يعرض:

- التعريف المهني المختصر.
- خدمات GIS والداشبوردات وأنظمة الويب.
- مشاريع مختارة بصيغة Case Study مصغرة.
- المهارات التقنية.
- طريقة العمل.
- وسائل التواصل.

## الاتجاه البصري

Dark Premium Glass / GIS Tech

- خلفية داكنة فاخرة.
- بطاقات زجاجية.
- تدرجات أزرق وتركواز.
- تجربة عربية RTL.
- تصميم مناسب للجوال.
- Bottom navigation للجوال.
- مودال تفاصيل لكل مشروع.
- دعم تبديل الوضع الداكن/الفاتح.

## التقنية

- React
- TypeScript
- Vite
- CSS responsive
- Framer Motion
- Lucide React
- GitHub Pages workflow

## التشغيل المحلي

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
```

ينتج البناء داخل مجلد `docs` لاستخدامه في GitHub Pages.

## النشر

تمت إضافة GitHub Actions workflow:

```text
.github/workflows/deploy.yml
```

بعد تفعيل GitHub Pages من إعدادات المستودع، سيتم النشر تلقائيًا عند كل Push على فرع `main`.
